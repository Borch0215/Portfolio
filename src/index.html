Sobre mí

Hola, soy Borja Gómez Frade, desarrollador full-stack con amplia experiencia en crear interfaces accesibles y soluciones backend ligeras. Mi enfoque combina rendimiento, experiencia de usuario y mantenibilidad.

Trabajo con HTML5, CSS3 modular, JavaScript moderno y PHP para entornos LAMP/WAMP/XAMPP. Prefiero soluciones simples y robustas: almacenamiento en JSON para prototipos y PHPMailer para flujos de correo seguros.

Servicios: Desarrollo web, UI/UX, integraciones API, optimización de rendimiento y accesibilidad (WCAG AA).
